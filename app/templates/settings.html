Setup checklist

  1. Create an app at Apps and Keys.
  2. Copy the integration key and (for Auth Code) the secret key into .env.
  3. Add a redirect URI matching {{ redirect_uri }}.
  4. Request the Agreement Manager scopes adm_store_unified_repo_read and public_dms_document_read.
  5. For JWT Grant: add an RSA key pair, save the private key, and set DOCUSIGN_USER_ID.
  6. Grant consent once (JWT) or click Connect (Auth Code).
  7. Restart the app after editing .env.

Credentials are read from the environment / .env and are never stored in the browser or committed to git.
